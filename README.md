# 🎵 Spotify Clone

A fully responsive Spotify-inspired music player built using **HTML, CSS, and JavaScript**. This project replicates the core user interface and functionality of Spotify's web player, including playlist browsing, music playback controls, volume adjustment, and responsive design.

---

## 📌 Overview

The Spotify Clone provides an interactive music streaming experience with a modern user interface. Users can browse playlists, play songs, control playback, adjust volume, and navigate seamlessly across devices.

---

## ✨ Features

### 🎶 Music Playback
- Play and pause songs
- Next and previous track controls
- Real-time song progress tracking
- Interactive seek bar

### 📂 Dynamic Playlist Management
- Automatically loads playlists
- Displays album covers and metadata
- Dynamic song listing using JavaScript

### 🔊 Audio Controls
- Volume adjustment slider
- Mute / Unmute functionality
- Song duration and current playback time display

### 📱 Responsive Design
- Mobile-friendly layout
- Hamburger menu navigation
- Adaptive sidebar behavior
- Optimized for desktop and mobile screens

### 🎨 Modern UI
- Spotify-inspired design
- Smooth hover animations
- Dark theme interface
- Custom scrollbar styling
